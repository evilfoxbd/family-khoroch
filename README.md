# পারিবারিক বাজার খরচ

টেলিগ্রামে সারাদিন এলোমেলোভাবে বাজারের কথা লিখবেন, রাত ১২টায় GitHub Actions সেটা
নিজে থেকে গুছিয়ে একটা দৈনিক রিপোর্ট বানিয়ে এই রিপোজিটরিতেই জমা করবে, আর একটা
ওয়েব ড্যাশবোর্ডেও (GitHub Pages) দেখা যাবে।

**⚠️ এই রিপো পাবলিক।** ড্যাশবোর্ডটা GitHub-এর ফ্রি Pages দিয়ে হোস্ট করা, যেটা প্রাইভেট
রিপোতে চলে না — তাই সব বাজারের মেসেজ ও খরচের হিসাব ইন্টারনেটে যে কেউ দেখতে পারবে
(লিংক অনুমান করলে বা রিপোর প্রোফাইলে গেলে)। সত্যিকারের প্রাইভেট চাইলে repo আবার
প্রাইভেট করে দিন (Settings → General → Danger Zone → Change visibility) — তাহলে
Pages বন্ধ হয়ে যাবে, কিন্তু `reports/expenses.csv` ও `.md` ফাইলগুলো github.com-এ
গিয়ে সরাসরি (প্রাইভেটভাবে) দেখা যাবে, শুধু কাস্টম চার্ট-ড্যাশবোর্ডটা থাকবে না।

## কীভাবে কাজ করে

```
টেলিগ্রাম চ্যাট
      │  (প্রতি ২০ মিনিটে)
      ▼
collect.py ──▶ data/raw/2026-09-12.jsonl        কাঁচা মেসেজ
      │  (রাত ১২টা ০৫)
      ▼
report.py  ──▶ reports/2026-09/2026-09-12.md    গোছানো রিপোর্ট
               reports/expenses.csv              হিসাবের খাতা
               docs/data/expenses.csv            ড্যাশবোর্ডের ডেটা
```

`collect.py` ঘন ঘন চলে কারণ টেলিগ্রাম না-পড়া মেসেজ মাত্র ২৪ ঘণ্টা রাখে — দিনে একবার
নিতে গেলে মেসেজ হারানোর ঝুঁকি থাকে। `report.py` দিনে একবার চলে, Gemini দিয়ে নোটগুলো
আইটেম-পরিমাণ-দাম-ক্যাটাগরিতে ভাগ করে।

## সেটআপ

### ১. টেলিগ্রাম bot বানান

1. টেলিগ্রামে [@BotFather](https://t.me/BotFather) খুলে `/newbot` দিন, নাম দিন।
2. যে **token** পাবেন সেটা রেখে দিন (`123456:ABC-DEF...`)।
3. নিজের bot-এর চ্যাটে গিয়ে যেকোনো একটা মেসেজ পাঠান ("test")।

> **গ্রুপে ব্যবহার করলে:** BotFather-এ `/setprivacy` → bot বেছে নিন → **Disable**।
> না করলে bot গ্রুপের সাধারণ মেসেজ দেখতেই পাবে না, শুধু কমান্ড দেখবে।

### ২. রিপো তৈরি করুন

এই ফোল্ডারটা একটা GitHub রিপোজিটরিতে তুলুন:

```bash
git init
git add .
git commit -m "initial commit"
git branch -M main
git remote add origin https://github.com/<আপনার-ইউজারনেম>/<রিপো>.git
git push -u origin main
```

### ৩. Secrets যোগ করুন

রিপোর **Settings → Secrets and variables → Actions → New repository secret**:

| নাম | মান | লাগবেই? |
| --- | --- | --- |
| `TELEGRAM_BOT_TOKEN` | BotFather-এর টোকেন | হ্যাঁ |
| `GEMINI_API_KEY` | [aistudio.google.com/apikey](https://aistudio.google.com/apikey) থেকে (Google অ্যাকাউন্ট দিয়ে ফ্রি) | না, তবে ছাড়া রিপোর্ট গোছানো হবে না |
| `TELEGRAM_ALLOWED_CHAT_IDS` | শুধু যে চ্যাটগুলো গুনবে, কমা দিয়ে | না |

### ৪. Actions-এর লেখার অনুমতি দিন

**Settings → Actions → General → Workflow permissions** → **Read and write permissions**।
এটা না দিলে রিপোর্ট কমিট হবে না।

### ৫. GitHub Pages চালু করুন (ড্যাশবোর্ডের জন্য)

**Settings → Pages** → Source: **Deploy from a branch** → Branch: **main**, folder **/docs** → **Save**।
এক-দুই মিনিট পর `https://<আপনার-ইউজারনেম>.github.io/<রিপো>/`-এ ড্যাশবোর্ড দেখা যাবে
(Pages ফ্রি প্ল্যানে শুধু পাবলিক রিপোতে চলে, তাই এটা লাগবে — উপরে দেখুন)।

### ৬. প্রথমবার চালিয়ে দেখুন

**Actions** ট্যাব → **Collect Telegram messages** → **Run workflow**। লগের শেষে
`Chat IDs seen this run:` লাইনে আপনার চ্যাট আইডি দেখাবে — চাইলে সেটা
`TELEGRAM_ALLOWED_CHAT_IDS` secret-এ বসিয়ে দিন, তাহলে অন্য কেউ bot-এ মেসেজ পাঠালেও
হিসাবে ঢুকবে না।

তারপর **Daily report** → **Run workflow** দিয়ে রিপোর্ট বানিয়ে দেখুন।

## লেখার নিয়ম

কোনো নিয়ম নেই — যেভাবে খুশি লিখুন:

```
চাল ৫ কেজি ৩৫০
আজ বাজারে ইলিশ ১২০০ টাকা কেজি, ১ কেজি নিলাম
ডিম ১ ডজন কিনতে হবে
রিকশা ভাড়া ৬০
```

Gemini নিজেই আলাদা করে নেবে — কোনটা কেনা হয়েছে, কোনটা কিনতে হবে, কোন
ক্যাটাগরিতে পড়ে। দাম বা পরিমাণ না লিখলে সেটা ফাঁকা থাকবে, বানিয়ে লেখা হবে না।
যে লাইন বোঝা যায়নি সেটা রিপোর্টের "বোঝা যায়নি" অংশে হুবহু থেকে যাবে।

## ফলাফল

- **ড্যাশবোর্ড** — `https://<আপনার-ইউজারনেম>.github.io/<রিপো>/` — মাস অনুযায়ী খরচের
  চার্ট, ক্যাটাগরি ব্রেকডাউন, "কিনতে হবে" লিস্ট, আর সার্চ-করা যায় এমন পুরো আইটেম টেবিল।
  প্রতিদিন রিপোর্ট তৈরি হলে অটো আপডেট হয়। দিনের যেকোনো সময় এখনই প্রসেস করাতে
  ড্যাশবোর্ডের বাটনও ব্যবহার করা যায় (নিচে দেখুন)।
- `reports/2026-09/2026-09-12.md` — দিনের রিপোর্ট: ক্যাটাগরি অনুযায়ী টেবিল, মোট খরচ,
  কিনতে-হবে চেকলিস্ট, আর নিচে আসল মেসেজগুলো।
- `reports/expenses.csv` — সব দিনের প্রতিটি আইটেম এক ফাইলে। Excel বা Google Sheets-এ
  খুলে মাস/ক্যাটাগরি ধরে হিসাব করতে পারবেন। ড্যাশবোর্ড এই ফাইলটাই পড়ে।
- `data/raw/` — কাঁচা মেসেজ, কখনো মুছবেন না; এখান থেকেই রিপোর্ট বানানো হয়।

## ড্যাশবোর্ডের "এখনই চালান" বাটন

`docs/index.html`-এ একটা বাটন আছে যেটা GitHub Actions-এর **Daily report**
workflow সরাসরি ড্যাশবোর্ড থেকেই চালু করে দেয় — রাত ১২টার জন্য অপেক্ষা না করেই
সেদিনের মেসেজ প্রসেস করে দেখা যায়।

এটা কাজ করতে একটা fine-grained token লাগে, যেটা **পেজের কোডেই বসানো থাকে** —
ইচ্ছাকৃতভাবে পাবলিক, কারণ পেজের সোর্স যে কেউ দেখতে পারে। সেটআপ:

1. **https://github.com/settings/personal-access-tokens/new**
2. Repository access → **Only select repositories** → এই রিপো বেছে নিন
3. Permissions → Repository permissions → **Actions** → **Read and write**
4. **Generate token**, ভ্যালুটা কপি করুন
5. `docs/index.html`-এ `TRIGGER_TOKEN` ভ্যারিয়েবলে বসান, কমিট করে push করুন

টোকেনটা শুধু এই রিপোর Actions চালাতে পারে — কোড/সিক্রেট পড়তে বা বদলাতে পারে না।
সবচেয়ে খারাপ যা হতে পারে: কেউ পেজের সোর্স দেখে বারবার বাটন চাপার মতো কল করলে
Gemini কোটা/Actions মিনিট অহেতুক খরচ হতে পারে — কোনো ডেটা ফাঁস বা কোড পরিবর্তনের
ঝুঁকি নেই। মেয়াদ শেষ হয়ে গেলে বাটন এরর দেখাবে; তখন নতুন টোকেন বানিয়ে আবার বসাতে হবে।

## নিজের কম্পিউটারে চালানো

```powershell
pip install -r requirements.txt
$env:TELEGRAM_BOT_TOKEN = "..."
$env:GEMINI_API_KEY = "..."
python scripts/collect.py
python scripts/report.py --date 2026-09-12
```

`--date` না দিলে "যে দিনটা এইমাত্র শেষ হলো" ধরে নেয় (বাংলাদেশ সময় অনুযায়ী)।
পুরনো কোনো দিনের রিপোর্ট আবার বানাতে চাইলে `--date` দিয়ে চালান — আগের রিপোর্ট আর
CSV-র ওই দিনের সারিগুলো নতুন করে লেখা হবে, ডুপ্লিকেট হবে না।

## মনে রাখার মতো কিছু কথা

- **রিপো পাবলিক — বানানো তথ্য (রান্নাঘরের বাজার, খরচ) যে কেউ দেখতে পারবে।** কোনো
  ব্যক্তিগত পরিচয়সূচক তথ্য (ঠিকানা, ফোন নম্বর, অ্যাকাউন্ট নম্বর) কখনো টেলিগ্রামে
  বাজারের নোট হিসেবে লিখবেন না।
- **GitHub-এর cron ঠিক সময়ে চলে না।** ব্যস্ত সময়ে ৫–৩০ মিনিট দেরি হতে পারে। রিপোর্ট
  তারিখ অনুযায়ী বানানো হয়, তাই দেরিতে চললেও হিসাব ঠিকই থাকে।
- **৬০ দিন কোনো কাজ না হলে** GitHub নিজে থেকে scheduled workflow বন্ধ করে দেয়।
  প্রতিদিন কমিট হওয়ায় সাধারণত সমস্যা হয় না, তবে Actions ট্যাবে মাঝে মাঝে চোখ রাখবেন।
- **bot-এর টোকেন কখনো কোডে লিখবেন না** — সবসময় GitHub Secrets-এ রাখুন।
- একই bot-এ `getUpdates` শুধু একজনই পড়তে পারে। bot-টি অন্য কোথাও ব্যবহার করবেন না,
  আর কোনো webhook সেট করা থাকলে মেসেজ আসবে না।

## খরচ

- GitHub Actions: প্রাইভেট রিপোতে ফ্রি কোটার মধ্যেই হয়ে যায় (দিনে ~৭২টা ছোট রান)।
  একদমই চিন্তা থাকলে `collect.yml`-এ `*/20` বদলে `0 * * * *` (প্রতি ঘণ্টায়) করে দিন।
- Gemini API: দিনে একটা ছোট রিকোয়েস্ট — [aistudio.google.com](https://aistudio.google.com)-এর
  ফ্রি টায়ারে এই পরিমাণ ব্যবহারে সাধারণত কোনো খরচই লাগে না। বিলিং একাউন্ট সেট না করলেও চলে।

> ফ্রি টায়ারে Google মাঝে মাঝে rate limit বা সাময়িক ত্রুটি দিতে পারে (বিশেষত ব্যস্ত সময়ে)।
> এমন হলে `report.py` এরর দিয়ে থেমে যাবে — Actions ট্যাব থেকে **Daily report** →
> **Run workflow** দিয়ে একই তারিখ দিয়ে আবার চালালেই হবে, আগের কোনো ডেটা নষ্ট হবে না।
